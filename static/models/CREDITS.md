## Estado: modelo temporal

Este modelo se usa **únicamente como referencia visual mientras se desarrolla la aplicación**. Es un
"concept car" de muestra, no un vehículo de producción específico — cuando el proyecto tenga un
modelo definitivo, reemplaza `static/models/car.glb` y actualiza este archivo con la nueva atribución
(o bórralo si el nuevo modelo es CC0 y no la requiere).
